# 康威生命游戏（Conway's Game of Life）

一个基于 **React + Vite** 的康威生命游戏实现，支持完全自定义初始状态，使用 HTML5 Canvas 渲染网格。

## 功能特性

- **鼠标绘制 / 擦除**：在网格上点击或拖拽即可切换细胞状态（起始点为活细胞则擦除，否则绘制）。
- **随机填充**：一键随机生成初始状态，密度可通过滑块调节（5%–90%）。
- **预设图案库**：内置 11 种经典图案，选中后点击网格即可放置。
  - 滑翔机、轻型飞船、闪烁灯、蟾蜍、方块、蜂巢、十五期虫、脉冲星、高斯帕滑翔机枪、R 五连体、橡果
- **导入 / 导出**：支持 RLE 与纯文本（`O` 表示活细胞，`.` 表示死细胞）格式互转，并可一键复制。
- **运行控制**：开始 / 暂停、单步、重置，速度可调（1–60 代/秒）。
- **网格设置**：可调行列数（3–300），边界模式支持**有限**（越界即死亡）与**环绕**（上下左右相连）。
- **实时统计**：显示当前代数、存活细胞数、网格大小与存活密度。

## 快速开始

```bash
npm install
npm run dev
```

打开终端提示的地址（默认 http://localhost:5173）。

## 构建

```bash
npm run build     # 生成生产构建到 dist/
npm run preview   # 本地预览生产构建
```

## 实现说明

- 网格使用 `Uint8Array` 存储，0 表示死亡、1 表示存活，内存占用低。
- 演化规则为标准规则 **B3/S23**：活细胞在 2 或 3 个活邻居时存活，死细胞在恰好 3 个活邻居时诞生（`src/logic/life.js`）。
- 边界模式：`finite` 越界视为死亡；`wrap` 取模实现环形网格。
- 演化循环使用 `setInterval`，通过 `useRef` 读取最新网格，避免闭包读取过期状态。
